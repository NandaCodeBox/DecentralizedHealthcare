## 🎙️ Voiceover Recording Tips

### Voice Characteristics
- **Accent**: Indian English (neutral, professional)
- **Tone**: Confident, clear, enthusiastic
- **Pace**: Moderate (not too fast, not too slow)
- **Energy**: High but controlled

### Recording Setup
1. **Microphone**: Use good quality mic (or phone in quiet room)
2. **Environment**: Quiet room, no background noise
3. **Distance**: 6-8 inches from mic
4. **Test**: Record 10 seconds, listen, adjust

### Voiceover Tools

**Option 1: Record Yourself**
- Use Audacity (free)
- Use phone voice recorder
- Use OBS Studio audio

**Option 2: AI Voice (Quick)**
- Use ElevenLabs (realistic Indian voice)
- Use Murf.ai (professional voiceover)
- Use Google Text-to-Speech (free, decent quality)

**Option 3: Hire Fiverr**
- Cost: $5-10
- Time: 24 hours
- Quality: Professional

## 🎬 Recording Workflow

### Step 1: Prepare (10 minutes)
1. ✅ Read script 3 times
2. ✅ Practice timing
3. ✅ Mark pauses
4. ✅ Test microphone

### Step 2: Record Screen (15 minutes)
1. ✅ Open OBS Studio / Loom
2. ✅ Set resolution: 1920x1080
3. ✅ Record screen actions (no audio yet)
4. ✅ Follow action items from script
5. ✅ Save as: `demo-screen-recording.mp4`

### Step 3: Record Voiceover (20 minutes)
1. ✅ Open Audacity / Voice recorder
2. ✅ Record voiceover following script
3. ✅ Do 2-3 takes
4. ✅ Choose best take
5. ✅ Save as: `demo-voiceover.mp3`

### Step 4: Combine (15 minutes)
1. ✅ Open video editor (DaVinci Resolve / iMovie / Shotcut)
2. ✅ Import screen recording
3. ✅ Import voiceover
4. ✅ Sync audio with video
5. ✅ Add title cards (optional)
6. ✅ Export as MP4 (H.264)

### Step 5: Upload (10 minutes)
1. ✅ Upload to YouTube (unlisted)
2. ✅ Add title: "Arogya AI Healthcare Platform - AWS AI Bharat Hackathon Demo"
3. ✅ Add description with links
4. ✅ Copy video URL
5. ✅ Add to submission
