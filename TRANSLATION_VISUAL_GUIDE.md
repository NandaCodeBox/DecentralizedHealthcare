## The Code Behind Each Text

### Example 1: Main Heading

**Code:**
```typescript
<h2>{t('get_right_care')}</h2>
```

**Translation Dictionary:**
```typescript
'get_right_care': {
  en: 'Get the Right Care, Right Now',
  hi: 'अभी सही देखभाल प्राप्त करें',
  ta: 'இப்போதே சரியான பராமரிப்பைப் பெறுங்கள்',
  te: 'ఇప్పుడే సరైన సంరక్షణ పొందండి',
}
```

**Result:**
- English: "Get the Right Care, Right Now"
- Hindi: "अभी सही देखभाल प्राप्त करें"
- Tamil: "இப்போதே சரியான பராமரிப்பைப் பெறுங்கள்"
- Telugu: "ఇప్పుడే సరైన సంరక్షణ పొందండి"

## What Happens When You Click

### Step 1: Click Hindi
```
User clicks: 🇮🇳 हिंदी Hindi
```

### Step 2: Save to Browser
```
localStorage.setItem('preferredLanguage', 'hi')
```

### Step 3: Page Reloads
```
window.location.reload()
```

### Step 4: Load Saved Language
```
const saved = localStorage.getItem('preferredLanguage')
// saved = 'hi'
```

### Step 5: Display Hindi Text
```
t('get_right_care')
// Returns: 'अभी सही देखभाल प्राप्त करें'
```

## Browser Storage

**Check in Browser Console (F12):**
```javascript
// See current language
localStorage.getItem('preferredLanguage')

// Output examples:
null          // English (default)
"hi"          // Hindi
"ta"          // Tamil
"te"          // Telugu
```
