## 🎥 RECORDING TIPS

### Before Recording:

1. **Practice Run**: Do a complete dry run without recording
2. **Clear Cache**: Ctrl+Shift+Delete, clear everything
3. **Incognito Mode**: Use private browsing to avoid cache issues
4. **Close Tabs**: Close all other browser tabs
5. **Disable Notifications**: Turn off system notifications
6. **Check Audio**: Test voiceover file playback
7. **Prepare Credentials**: Have login details ready

### During Recording:

1. **Smooth Mouse Movement**: Move cursor slowly and deliberately
2. **Pause on Key Screens**: Let viewers see important information
3. **Don't Rush**: Follow the timing guide, but prioritize clarity
4. **Show Loading States**: Let AI processing animations play
5. **Highlight Key Features**: Hover over important elements
6. **Keep Cursor Visible**: Don't hide the mouse cursor

### After Recording:

1. **Review Video**: Watch the entire recording
2. **Check Timing**: Ensure it's close to 3 minutes
3. **Verify Audio**: Make sure voiceover is clear
4. **Check Quality**: Ensure text is readable
5. **Export**: Save as MP4, 1080p, 30fps
