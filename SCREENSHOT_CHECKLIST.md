## 🎯 Pro Tips

1. **Clean Browser**: Use incognito mode for clean screenshots (no extensions, bookmarks)
2. **Full Screen**: Press `F11` for fullscreen before screenshot (optional)
3. **High Resolution**: Take screenshots at 100% zoom for clarity
4. **Consistent Size**: Try to capture similar areas for consistency
5. **Good Lighting**: If taking photos of screen, ensure good lighting
6. **Backup**: Save screenshots in multiple locations

## 🆘 Troubleshooting

**Problem**: Can't switch to Hindi/Tamil
**Solution**: Refresh page, language selector should be in top-right corner

**Problem**: Symptom intake not working
**Solution**: Make sure you're logged in, try test@arogya.ai / Test@123

**Problem**: Provider search returns no results
**Solution**: Try simpler query like "Doctor" or "Cardiologist"

**Problem**: Supervisor dashboard empty
**Solution**: Submit a few symptom assessments first to populate cases

**Problem**: Mobile view not showing
**Solution**: Press F12, then Ctrl+Shift+M, select device from dropdown
